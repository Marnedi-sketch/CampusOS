# 🎓 CampusOS — Smart Campus Management System

CampusOS is a web-based campus management application designed to help students organize academic tasks, explore campus events, read college announcements, and report lost or found items in one place.

## ✨ Features

- 📋 **Task Management** — Create and manage your daily tasks.
- 📅 **Campus Events** — View upcoming college events.
- 📢 **Notice Board** — Stay updated with campus announcements.
- 🔍 **Lost & Found** — Report and find lost belongings.
- 🔐 **Authentication** — Register and sign in to your account.
- ☁️ **Firebase Integration** — Connect the application to Firebase services.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Marnedi-sketch/CampusOS.git
   ```

2. Open the project folder in Visual Studio Code.
3. Run `index.html` using the Live Server extension.
4. Ensure your Firebase project configuration and security rules are set up correctly.
